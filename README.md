# 🌿 Pokémon Emerald Version - RPG Web Edition

A complete, faithful **Pokémon Emerald GBA-style RPG** built from scratch in HTML5 Canvas and Vanilla JavaScript.

![Pokemon Emerald](https://raw.githubusercontent.com/PokeAPI/sprites/master/sprites/pokemon/other/showdown/384.gif)

## 🎮 Features
- **Authentic Game Boy Advance SP Shell**: Retro emerald green handheld console with interactive D-Pad, A/B buttons, and fullscreen toggle.
- **Hoenn Starters Selection**: Choose between **Treecko** (Grass), **Torchic** (Fire), or **Mudkip** (Water)!
- **Overworld Exploration**:
  - **Littleroot Town**: Player House, Professor Birch's Lab, Mom (party heal & Running Shoes).
  - **Route 101**: Tall grass wild encounters, ledges, and item drops.
  - **Oldale Town**: Pokémon Center (Nurse Joy recovery sequence) & Pokémart.
  - **Sky Pillar Shrine**: Northern ancient altar with Legendary Boss **Rayquaza**!
- **Emerald Turn-Based Battle Engine**:
  - 4 Commands: `FIGHT`, `BAG`, `POKéMON`, `RUN`.
  - Type effectiveness, STAB, critical hits, PP, accurate damage formulas.
  - Catching mechanics with Poké Balls and Great Balls (authentic ball wobbles and clicks).
  - Starter Evolution at Level 16 (Treecko ➔ Grovyle, Torchic ➔ Combusken, Mudkip ➔ Marshtomp).
- **Pure Web Audio Synthesizer**: Retro 8-bit / GBA chiptune music tracks and sound effects generated live via the Web Audio API with zero external audio assets.
- **Save & Load**: In-game menu save system storing team, bag, levels, and progress to `localStorage`.

## 🕹️ Controls
| Action | Key |
|---|---|
| Movement | Arrow Keys or W, A, S, D |
| Sprint (Running Shoes) | Hold Shift or X |
| A Button (Interact / Select) | Z, Space, or Enter |
| B Button (Cancel / Back) | X or Backspace |
| Start Menu | C, M, or Escape |
| Mute / Unmute Audio | M |
